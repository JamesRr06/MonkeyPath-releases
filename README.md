# Monkey Path — versions de l'alpha

Dépôt public de **Monkey Path** (éditeur : Monkey Family). Il héberge :

- les pages de l'alpha fermée (installation, confidentialité, conditions d'utilisation), publiées par GitHub Pages ;
- les APK signés de l'alpha, dans l'onglet **Releases**.

Le code du jeu n'est pas ici. Les pages sont copiées depuis `site/` du dépôt du jeu par `tools/publier_release.ps1`.
